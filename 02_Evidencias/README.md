# Evidencias del proyecto

Esta carpeta reúne el índice de productos verificables y los criterios para publicar evidencias de manera segura.

- [Índice de evidencias](Indice_evidencias.md)
- [Protocolo de confidencialidad](Protocolo_confidencialidad.md)

No se deben cargar datos personales, formularios diligenciados, historias individuales ni información sensible de jóvenes atendidos. Los registros individualizados deben permanecer en sistemas institucionales autorizados.
